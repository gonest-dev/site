---
title: Exceptions & Panic Recovery
description: HttpException, excepciones integradas y el contrato de recuperación de panic
---

gonest.HttpException es el tipo base que toda excepción gonest embebe.

`go
gonest.NewHttpException().
  SetStatus(http.StatusBadRequest).
  SetName("FooError").
  SetMessage("lorem ipsum").
  SetDetails(details)
`

Cualquier tipo que embeba HttpException satisface estructuralmente la interfaz
Exception — la capa de recovery usa type-assertion, nunca un type-switch cerrado.

## Excepciones integradas

Todos los constructores aceptan (message string, details ...any). Pasar "" como
message usa el default del tipo (ej: "Resource not found" para NotFoundException).
Los 40 tipos de error HTTP estándar están disponibles — ver la lista completa en
[Referencia de API → Exceptions](/docs/api-reference/exceptions).

`go
panic(gonest.NewNotFoundException("", map[string]any{"id": id}))
panic(gonest.NewUnauthorizedException("Token expirado", nil))
panic(gonest.NewTooManyRequestsException("", nil))
panic(gonest.NewInternalServerErrorException("", err.Error()))
`

## Excepciones personalizadas

Embeba gonest.HttpException exactamente como una excepción integrada:

`go
type FooError struct{ gonest.HttpException }

func NewFooError(details any) *FooError {
  return &FooError{
    HttpException: gonest.NewHttpException().
      SetStatus(http.StatusBadRequest).
      SetName("FooError").
      SetMessage("lorem ipsum").
      SetDetails(details),
  }
}
`

## Contrato panic → respuesta

<Callout type="info">
  Cualquier panic con un valor que satisfaga Exception se convierte en JSON
  {"name": ..., "message": ..., "details": ...} con el status de la excepción.
  Cualquier **otro** panic (nil pointer, index out of range, etc.) se convierte en
  un 500 genérico con **cero detalle interno filtrado** — el proceso nunca colapsa.
</Callout>

## Constantes de estado HTTP

gonest.HttpStatus* reexporta las 63 constantes estándar 
et/http.StatusXxx
bajo el namespace gonest (ej: gonest.HttpStatusNotFound), para que el código
de handler nunca necesite importar 
et/http solo por status codes.
