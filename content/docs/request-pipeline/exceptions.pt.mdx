---
title: Exceptions & Panic Recovery
description: HttpException, exceções embutidas e o contrato de recuperação de panic
---

gonest.HttpException é o tipo base que toda exceção gonest embute.

`go
gonest.NewHttpException().
  SetStatus(http.StatusBadRequest).
  SetName("FooError").
  SetMessage("lorem ipsum").
  SetDetails(details)
`

Qualquer tipo que embuta HttpException satisfaz estruturalmente a interface
Exception — a camada de recovery usa type-assertion, nunca um type-switch fechado.

## Exceções embutidas

Todos os construtores aceitam (message string, details ...any). Passar "" como
message usa o default do tipo (ex: "Resource not found" para NotFoundException).
Todos os 40 tipos de erro HTTP padrão estão disponíveis — veja a lista completa em
[Referência de API → Exceptions](/docs/api-reference/exceptions).

`go
panic(gonest.NewNotFoundException("", map[string]any{"id": id}))
panic(gonest.NewUnauthorizedException("Token expirado", nil))
panic(gonest.NewTooManyRequestsException("", nil))
panic(gonest.NewInternalServerErrorException("", err.Error()))
`

## Exceções customizadas

Embuta gonest.HttpException exatamente como uma exceção embutida:

`go
type FooError struct{ gonest.HttpException }

func NewFooError(details any) *FooError {
  return &FooError{
    HttpException: gonest.NewHttpException().
      SetStatus(http.StatusBadRequest).
      SetName("FooError").
      SetMessage("lorem ipsum").
      SetDetails(details),
  }
}
`

## Contrato panic → resposta

<Callout type="info">
  Qualquer panic com um valor que satisfaça Exception vira JSON
  {"name": ..., "message": ..., "details": ...} com o status da exceção.
  Qualquer **outro** panic (nil pointer, index out of range, etc.) vira um
  500 genérico com **zero detalhe interno vazado** — o processo nunca crasha.
</Callout>

## Constantes de status HTTP

gonest.HttpStatus* reexporta todas as 63 constantes padrão 
et/http.StatusXxx
sob o namespace gonest (ex: gonest.HttpStatusNotFound), então o código de
handler nunca precisa importar 
et/http só por status codes.
