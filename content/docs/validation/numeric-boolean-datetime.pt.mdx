## Numeric

`Integer()` (formato `int64`), `Int32()`, `Float()`, `Double()` compartilham
`Min(int)`/`Max(int)`:

```go
s.Property(&t.Age).Integer().Required().Min(0).Max(150)
```

## Boolean, Date & DateTime — ramificações sem wrappers

`Boolean()`, `Date()` (formato `date`) e `DateTime()` (formato `date-time`)
são ramificações "sem wrappers" — sem validadores extras além dos quatro
base (`Required`/`Nullable`/`Description`/`Examples`). Eles retornam um
`*PropertyBuilder` puro diretamente.

```go
s.Property(&t.Active).Boolean().Required()
s.Property(&t.BornAt).Date().Required()
s.Property(&t.CreatedAt).DateTime().Required()
```

## Duration

`Duration()` mira um campo `time.Duration`. Diferente de `Date`/`DateTime`,
ele TEM validadores extras — `Min(time.Duration)`, `Max(time.Duration)` e
`Enum(items ...time.Duration)` — porque um limite de duração precisa
comparar o VALOR parseado, não o tamanho da string.

```go
s.Property(&t.RelayInterval).
  Duration().
  Min(1 * time.Second).
  Max(1 * time.Hour).
  Default(5 * time.Second)
```

O formato de transporte é a string de duração nativa do Go (`"5s"`,
`"1h30m"`, parseada via `time.ParseDuration`) — não ISO-8601. Funciona da
mesma forma em qualquer origem: JSON body, path/query params, headers,
campos de form e variáveis de ambiente. Uma string inválida (ex:
`"not-a-duration"`) ou um valor fora do limite produz uma violação de
validação por campo normal, igual a qualquer outra ramificação.
