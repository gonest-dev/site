`gonest.NewModule(func(module *gonest.Module) {...})`

| Method | Description |
|---|---|
| `Providers(...TokenRef)` | Register providers owned by this module. |
| `Controllers(...TokenRef)` | Register controllers owned by this module. |
| `Imports(...TokenRef)` | Import other modules, gaining access to their exported providers. |
| `Exports(...TokenRef)` | Expose providers, or re-export a whole imported `*Module` (its own exports become visible transitively), to modules that import this one — accepts either in the same call. |
| `Lazy(func(l *gonest.LazyModule) {...})` | Decide, synchronously and from inside the DI graph, which module(s) to `Imports`/`Exports` — based on a config value read via `gonest.MustInject[T](l)` from this same module's own `Providers(...)`. gonest's equivalent to NestJS's `DynamicModule.forRootAsync`. |
| `Use(...TokenRef)` | Register global middleware. Root module only. |
| `Filters(...TokenRef)` | Register global exception filters. Root module only. |
| `Listeners(...TokenRef)` | Register event listeners. |
| `Schedulers(...TokenRef)` | Register scheduler jobs. |
| `Name("...")` | Set a readable name used in error messages. |

Every builder method accepts `...gonest.TokenRef` — the marker interface implemented by all DI entities. By convention in GoNest projects, declared reference variables end with a trailing underscore (`_`).

## Code Examples

### Feature Module Declaration (`UserModule_`)

```go
package user

import "gonest.dev/gonest"

// By convention in GoNest, module reference variables end with a trailing underscore (_)
var UserModule_ = gonest.NewModule(func(m *gonest.Module) {
	m.Name("UserModule")

	// Providers owned by this module
	m.Providers(
		PgUserRepository_,
		UserRepository_,
		UserServiceProvider_,
	)

	// Controllers owned by this module
	m.Controllers(
		UserController_,
	)

	// Providers exported for importing modules
	m.Exports(
		UserRepository_,
		UserServiceProvider_,
	)
})
```

### Importing in a Root Module (`AppModule_`)

```go
package app

import (
	"gonest.dev/gonest"
	"your-project/user"
)

var AppModule_ = gonest.NewModule(func(m *gonest.Module) {
	m.Name("AppModule")

	// Import feature modules
	m.Imports(
		user.UserModule_,
	)

	// Global middleware registered at root module level
	m.Use(
		LoggerMiddleware_,
	)
})
```

### Reusing `TokenRef` Slices

You can declare a shared slice of tokens and reuse it across methods:

```go
var commonProviders = []gonest.TokenRef{
	PgUserRepository_,
	UserRepository_,
}

var UserModule_ = gonest.NewModule(func(m *gonest.Module) {
	m.Providers(commonProviders...)
	m.Exports(commonProviders...) // Reused slice without conversion
})
```
