`gonest.NewController(func(controller *gonest.Controller) {...})`

| Método | Descrição |
|---|---|
| `Path("/prefix")` | Prefixo de caminho para todas as rotas neste Controller. |
| `Tags("...")` | Tags do OpenAPI, herdadas por todas as rotas, a menos que sobrescritas. |
| `BearerAuth()` | Marca todas as rotas como requerendo autenticação bearer, a menos que sobrescritas. |
| `Use(...)` | Middleware no escopo do Controller. |
| `Guards(...)` | Guards no escopo do Controller. |
| `Interceptors(...)` | Interceptors no escopo do Controller. |
| `Filters(...)` | Filters de exceção no escopo do Controller. |
| `Route(method, path, fn)` | Declaração genérica de rota. `fn` roda imediatamente e recebe o `*gonest.Route` recém-criado. |
| `RouteGet(path, fn)` / `RoutePost(path, fn)` / `RoutePut(path, fn)` / `RoutePatch(path, fn)` / `RouteDelete(path, fn)` / `RouteHead(path, fn)` / `RouteOptions(path, fn)` / `RouteTrace(path, fn)` / `RouteConnect(path, fn)` / `RouteQuery(path, fn)` | Atalhos por verbo HTTP. Nenhum deles retorna valor — construa a rota inteira dentro de `fn`. |

## Métodos de documentação do `Route` (Swagger / OpenAPI)

Todo método abaixo é um método do `*gonest.Route` recebido em `fn`, e
retorna esse mesmo `*gonest.Route` para permitir encadeamento.

| Método | Descrição |
|---|---|
| `Summary(...)` | Resumo curto da operação para a UI do Swagger. |
| `Description(...)` | Descrição detalhada da rota no Swagger. |
| `OperationId(...)` | ID único da operação no spec do OpenAPI. |
| `Tags(...)` | Define ou sobrescreve as tags do Controller para esta rota. |
| `BearerAuth()` | Marca a rota individual com suporte a autenticação Bearer. |
| `RequestBody(schema)` | Associa um schema de validação/documentação ao corpo da requisição. |
| `Response(status, fn...)` | Documenta um código de status; o callback opcional recebe um `*gonest.Response` para `.Schema(...)`/`.Description(...)`. |
| `Params(schema)` | Documenta os parâmetros de caminho (ex: `:id`). |
| `Query(schema)` | Documenta os parâmetros de busca (query string). |
| `ExcludeFromDocs()` | Oculta a rota da documentação Swagger gerada. |
| `Deprecated()` | Marca a rota como obsoleta (deprecated) no Swagger. |
| `Handler(fn)` | Armazena `fn` como o handler de requisição da rota. Não retorna valor — chame por último. |
| `Redirect(url, status...)` | Registra esta rota como um redirect estático para `url` — açúcar sobre `Handler`, sem precisar de handler. `status` usa `gonest.HttpStatusFound` (302) como padrão. |

Por convenção nos projetos GoNest, referências são declaradas como variáveis de pacote com um underline no final (`_`).

## Injetando dependências por rota

`gonest.MustInject[T]`/`gonest.MustInjectAll[T]` também funcionam de dentro
do `fn` de uma rota, não só no topo do builder do Controller — basta passar
o próprio `*gonest.Route` como owner. A resolução usa exatamente o mesmo
escopo de módulo que o Controller usaria, então um Controller com várias
rotas pode manter a dependência de cada rota junto do handler que
realmente a usa, em vez de empilhar todos os usecases no topo do
Controller:

```go
c.RouteGet("/:id", func(r *gonest.Route) {
	userRepo := gonest.MustInject[UserRepository](r)

	r.Summary("Get user by id")
	r.Handler(func(ctx *gonest.HttpContext) {
		user, err := userRepo.FindByID(ctx.Request().Param("id"))
		if err != nil {
			ctx.Response().Status(gonest.HttpStatusNotFound).Json(map[string]string{"error": "user not found"})
			return
		}
		ctx.Response().Status(gonest.HttpStatusOk).Json(user)
	})
})
```

Veja: [Onde `MustInject` pode ser chamado](/docs/core-concepts/dependency-injection#where-mustinject-can-be-called).

## Redirecionamentos

O GoNest espelha a ergonomia do `@Redirect()` do NestJS com dois métodos,
ambos usando `gonest.HttpStatusFound` (302, igual ao padrão do NestJS) por
padrão — `status` é um argumento final opcional que sobrescreve isso:

- **Dinâmico** — `ctx.Response().Redirect(url, status...)`, chamado de
  dentro de um `Handler`, para uma URL só conhecida em runtime (ex: a URL
  de callback do OAuth calculada por um usecase):

  ```go
  r.Handler(func(ctx *gonest.HttpContext) {
  	authURL, err := ssoUseCase.Execute(provider)
  	if err != nil {
  		panic(err)
  	}
  	ctx.Response().Redirect(authURL) // 302 por padrão
  })
  ```

- **Estático** — `r.Redirect(url, status...)`, declarado direto na rota,
  sem precisar de `Handler`, para um destino fixo:

  ```go
  c.RouteGet("/docs", func(r *gonest.Route) {
  	r.Redirect("/docs/", gonest.HttpStatusMovedPermanently)
  })
  ```

## Exemplos de uso

### Declaração de Controller com Swagger / OpenAPI

O exemplo abaixo demonstra como declarar um `UserController_`, definir prefixo de rotas, aplicar Guards e encadear declarações do Swagger para documentação automática:

```go
package user

import (
	"gonest.dev/gonest"
)

// Por convenção no GoNest, a referência do controller termina com um underline (_)
var UserController_ = gonest.NewController(func(c *gonest.Controller) {
	c.Path("/users")
	c.Tags("Users")
	c.Guards(AuthGuard_)

	// GET /users/:id - Buscar usuário por ID, dependência injetada por rota
	c.RouteGet("/:id", func(r *gonest.Route) {
		userRepo := gonest.MustInject[UserRepository](r)

		r.Summary("Get user by ID").
			Description("Fetches a user profile given a unique identifier.").
			Params(UserIdParamSchema_).
			Response(gonest.HttpStatusOk, func(response *gonest.Response) {
				response.Schema(UserResponseSchema_)
			}).
			Response(gonest.HttpStatusNotFound, func(response *gonest.Response) {
				response.Schema(ErrorResponseSchema_)
			})

		r.Handler(func(ctx *gonest.HttpContext) {
			user, err := userRepo.FindByID(ctx.Request().Param("id"))
			if err != nil {
				ctx.Response().Status(gonest.HttpStatusNotFound).Json(map[string]string{"error": "user not found"})
				return
			}
			ctx.Response().Status(gonest.HttpStatusOk).Json(user)
		})
	})

	// POST /users - Criar novo usuário com validação de corpo e respostas Swagger
	c.RoutePost("", func(r *gonest.Route) {
		userRepo := gonest.MustInject[UserRepository](r)

		r.Summary("Create new user").
			Description("Registers a new user account with validated JSON input.").
			RequestBody(CreateUserSchema_).
			Response(gonest.HttpStatusCreated, func(response *gonest.Response) {
				response.Schema(UserResponseSchema_)
			}).
			Response(gonest.HttpStatusBadRequest, func(response *gonest.Response) {
				response.Schema(ErrorResponseSchema_)
			})

		r.Handler(func(ctx *gonest.HttpContext) {
			body := gonest.MustParse[CreateUserDto](ctx.Request().Body().Json(), CreateUserSchema_)

			user, err := userRepo.Create(body.Name, body.Email)
			if err != nil {
				ctx.Response().Status(gonest.HttpStatusBadRequest).Json(map[string]string{"error": err.Error()})
				return
			}
			ctx.Response().Status(gonest.HttpStatusCreated).Json(user)
		})
	})
})
```
