`gonest.NewController(func(controller *gonest.Controller) {...})`

| Method | Description |
|---|---|
| `Path("/prefix")` | Path prefix for every route in this controller. |
| `Tags("...")` | OpenAPI tags, inherited by every route unless overridden. |
| `BearerAuth()` | Mark every route as requiring bearer auth, unless overridden. |
| `Use(...)` | Controller-scoped middleware. |
| `Guards(...)` | Controller-scoped guards. |
| `Interceptors(...)` | Controller-scoped interceptors. |
| `Filters(...)` | Controller-scoped exception filters. |
| `Route(method, path, fn)` | Generic route declaration. |
| `RouteGet(path, fn)` / `RoutePost(path, fn)` / `RoutePut(path, fn)` / `RoutePatch(path, fn)` / `RouteDelete(path, fn)` / `RouteHead(path, fn)` / `RouteOptions(path, fn)` / `RouteTrace(path, fn)` / `RouteConnect(path, fn)` / `RouteQuery(path, fn)` | Per-verb shorthands. |

## `Route` Documentation Methods (Swagger / OpenAPI)

| Method | Description |
|---|---|
| `Summary(...)` | Short operation summary for Swagger UI. |
| `Description(...)` | Detailed operation description in Swagger. |
| `OperationId(...)` | Unique operation identifier in OpenAPI spec. |
| `Tags(...)` | Set or override controller tags for this route. |
| `BearerAuth()` | Mark an individual route as supporting Bearer auth. |
| `RequestBody(schema)` | Attach request body validation schema to Swagger documentation. |
| `Response(status, schema...)` | Document an HTTP status response code and its optional response schema. |
| `PathParams(schema)` | Document path parameters (e.g. `:id`). |
| `QueryParams(schema)` | Document query string parameters. |
| `ExcludeFromDocs()` | Hide route from generated Swagger documentation. |
| `Deprecated()` | Mark route as deprecated in Swagger. |

By convention in GoNest projects, declared reference variables end with a trailing underscore (`_`).

## Code Examples

### Controller Declaration with Swagger / OpenAPI Metadata

The example below demonstrates how to declare a `UserController_`, configure a route prefix, attach guards, and chain Swagger metadata for automatic OpenAPI documentation generation:

```go
package user

import (
	"net/http"
	"github.com/gonest/gonest"
)

// By convention in GoNest, controller reference variables end with a trailing underscore (_)
var UserController_ = gonest.NewController(func(c *gonest.Controller) {
	c.Path("/users")
	c.Tags("Users")
	c.Guards(AuthGuard_)

	// GET /users/:id - Get user by ID with chained Swagger metadata
	c.RouteGet("/:id", func(req *gonest.Request, res *gonest.Response) {
		id := req.Param("id")
		
		// Inject dependency from DI container
		userRepo := gonest.MustInject[UserRepository](req)
		
		user, err := userRepo.FindByID(id)
		if err != nil {
			res.Status(http.StatusNotFound).JSON(gonest.Map{"error": "User not found"})
			return
		}
		
		res.Status(http.StatusOK).JSON(user)
	}).
	Summary("Get user by ID").
	Description("Fetches a user profile given a unique identifier.").
	PathParams(UserIdParamSchema_).
	Response(http.StatusOK, UserResponseSchema_).
	Response(http.StatusNotFound, ErrorResponseSchema_)

	// POST /users - Create new user with request validation and Swagger responses
	c.RoutePost("", func(req *gonest.Request, res *gonest.Response) {
		var body CreateUserDto
		req.MustParseRestJsonBody(&body)
		
		userRepo := gonest.MustInject[UserRepository](req)
		user, err := userRepo.Create(body.Name, body.Email)
		if err != nil {
			res.Status(http.StatusBadRequest).JSON(gonest.Map{"error": err.Error()})
			return
		}
		
		res.Status(http.StatusCreated).JSON(user)
	}).
	Summary("Create new user").
	Description("Registers a new user account with validated JSON input.").
	RequestBody(CreateUserSchema_).
	Response(http.StatusCreated, UserResponseSchema_).
	Response(http.StatusBadRequest, ErrorResponseSchema_)
})
```
