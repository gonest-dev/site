`gonest.NewSchema[T](func(t *T, s *gonest.Schema) {...})`

| Method | Description |
|---|---|
| `Title("...")` | Name in `components.schemas` (defaults to Go type name). |
| `Property(&t.X)` | Identify field by pointer, returns `*PropertyBuilder`. |

## Base Constraints (All Branches)

`Required()`, `Nullable()`, `Description("...")`, `Examples(...)`

## Property Branches

| Branch | Returns | Notes |
|---|---|---|
| `String()`, `Email()`, `Uuid()`, `Uri()`, `Hostname()`, `Ipv4()`, `Ipv6()`, `Password()`, `Byte()`, `Binary()` | `*StringMetadata` | `Min`/`Max`/`Pattern` |
| `Integer()`, `Int32()`, `Float()`, `Double()` | `*NumericMetadata` | `Min`/`Max` |
| `Boolean()`, `Date()`, `DateTime()` | `*PropertyBuilder` | wrapper-less, base constraints only |
| `Array()` | `*ArrayMetadata` | dual-state (container vs. item), see `.Items(fn)` |
| `Object(fn)` | `*ObjectMetadata` | single-state, `.Metadata(ref)` / `.AdditionalProperties()` |
| `Custom(fn func(raw any) (any, error))` | `*PropertyBuilder` | universal escape hatch |

## Parsing Functions

`gonest.MustParse[T](src, schema) T` / `gonest.Parse[T](src, schema) (T, error)`, where `src` is one of `req.Params()`, `req.Query()`, `req.Headers()`, `req.Body().Json()`, or `req.Body().Form(onFile)`.

By convention in GoNest projects, schema reference variables end with a trailing underscore (`_`).

## Code Examples

### Schema Declaration with DTO Validation Rules

```go
package user

import (
	"time"
	"github.com/gonest/gonest"
)

type CreateUserDto struct {
	Name      string    `json:"name"`
	Email     string    `json:"email"`
	Age       int       `json:"age"`
	IsActive  bool      `json:"isActive"`
	Tags      []string  `json:"tags"`
	CreatedAt time.Time `json:"createdAt"`
}

// By convention in GoNest, schema reference variables end with a trailing underscore (_)
var CreateUserSchema_ = gonest.NewSchema(func(t *CreateUserDto, s *gonest.Schema) {
	s.Title("CreateUserDto")

	s.Property(&t.Name).String().Min(2).Max(100).Required().
		Description("User's full name")

	s.Property(&t.Email).Email().Required().
		Description("Valid contact email address")

	s.Property(&t.Age).Integer().Min(18).Max(120).Required().
		Description("User age (minimum 18 years)")

	s.Property(&t.IsActive).Boolean().Required()

	// Array validation: defines item rules inside .Items() and array bounds on parent (.Min / .Max)
	s.Property(&t.Tags).Array().
		Items(func(m *gonest.StringMetadata) {
			m.Min(1)
		}).Min(1).Max(5).Required()

	s.Property(&t.CreatedAt).DateTime().Required()
})
```

### Runtime Validation with `MustParse`

```go
// Parsing raw payload into a validated DTO struct
rawInput := map[string]any{
	"name":      "Alice Smith",
	"email":     "alice@example.com",
	"age":       28,
	"isActive":  true,
	"tags":      []string{"admin", "dev"},
	"createdAt": "2026-07-24T18:00:00Z",
}

// Returns a strongly-typed and validated CreateUserDto struct
userDto := gonest.MustParse[CreateUserDto](rawInput, CreateUserSchema_)
```
