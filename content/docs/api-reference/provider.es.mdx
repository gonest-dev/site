`gonest.NewProvider(func(provider *gonest.Provider) {...})`

| Método | Descripción |
|---|---|
| `Scope(gonest.ScopeSingleton \| ScopeTransient \| ScopeRequest)` | Define el tiempo de vida (lifetime) de la instancia. |
| `Constructor(fn)` | `fn` es uno de `func() T`, `func() (T, error)`, `func(ctx) T`, `func(ctx) (T, error)`. |

## Funciones de resolución

| Función | Comportamiento |
|---|---|
| `MustInject[T](owner)` | Resuelve exactamente una coincidencia; lanza panic si hay 0 o N. |
| `MustInjectAll[T](owner)` | Resuelve todas las coincidencias. Nunca lanza panic en 0 o N coincidencias — excepto desde un owner `Provider`, donde un Provider `ScopeTransient` que coincida hace que `NewApp`/`MustNewApp` lance panic (solo los Providers `ScopeSingleton` pueden ser miembros del slice en ese caso). |
| `ProviderAs[T any](ref ProviderRef) ProviderRef` | Envuelve (wrap) `ref`, registrándolo como la interfaz `T` — la única forma en que `T` sea resolbible por `MustInject`/`MustInjectAll`. El registro concreto del propio `ref` también debe pasarse a `Providers(...)`. Lanza panic inmediatamente si `T` no es una interfaz, o si `ref` es el resultado de otra llamada a `ProviderAs` (encadenamiento). |

## Ejemplos de uso

### Ejemplo básico de Provider

```go
package user

import "github.com/gonest/gonest"

type UserService struct{}

func NewUserService() *UserService {
	return &UserService{}
}

var UserServiceProvider_ = gonest.NewProvider(func(p *gonest.Provider) {
	p.Scope(gonest.ScopeSingleton)
	p.Constructor(NewUserService)
})
```

### Registrando Constructor para Interfaz con `ProviderAs`

En GoNest, por convención, las referencias terminan con un guion bajo (`_`) y para inyectar una interfaz en lugar de un tipo concreto (similar al patrón de NestJS `{ provide: 'IUserRepository', useClass: PgUserRepository }`), utiliza `gonest.ProviderAs[T]`:

```go
package user

import "github.com/gonest/gonest"

type UserRepository interface {
	FindByID(id string) (*User, error)
}

type PgUserRepository struct{}

func NewPgUserRepository() *PgUserRepository {
	return &PgUserRepository{}
}

func (r *PgUserRepository) FindByID(id string) (*User, error) {
	return &User{ID: id}, nil
}

// 1. Define el provider de la implementación concreta (sufijo _)
var PgUserRepository_ = gonest.NewProvider(func(p *gonest.Provider) {
	p.Constructor(NewPgUserRepository)
})

// 2. Asocia la implementación concreta a la interfaz UserRepository (sufijo _)
var UserRepository_ = gonest.ProviderAs[UserRepository](PgUserRepository_)

// 3. Registra ambos en el Módulo (el provider concreto y el alias de la interfaz)
var UserModule_ = gonest.NewModule(func(m *gonest.Module) {
	m.Providers(PgUserRepository_, UserRepository_)
})
```

### Resolviendo Instancias con `MustInject` e `MustInjectAll`

Una vez que la interfaz esté registrada con `ProviderAs`, puedes resolverla usando la interfaz como parámetro de tipo:

```go
// Resuelve la única implementación de la interfaz UserRepository (lanza panic si hay 0 o más de 1)
userRepo := gonest.MustInject[UserRepository](owner)

// Resuelve todas las implementaciones registradas para la interfaz UserRepository
allRepos := gonest.MustInjectAll[UserRepository](owner)
```
