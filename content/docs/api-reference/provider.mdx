`gonest.NewProvider(func(provider *gonest.Provider) {...})`

| Method | Description |
|---|---|
| `Scope(gonest.ScopeSingleton \| ScopeTransient \| ScopeRequest)` | Set instance lifetime. |
| `Constructor(fn)` | `fn` is one of `func() T`, `func() (T, error)`, `func(ctx) T`, `func(ctx) (T, error)`. |

## Resolution functions

| Function | Behavior |
|---|---|
| `MustInject[T](owner)` | Resolves exactly one match; panics on 0 or N. |
| `MustInjectAll[T](owner)` | Resolves every match. Never panics on 0 or N matches — except from a `Provider` owner, where a matched `ScopeTransient` provider makes `NewApp`/`MustNewApp` panic (only `ScopeSingleton` providers can be slice members there). |
| `ProviderAs[T any](ref ProviderRef) ProviderRef` | Wraps `ref`, registering it as interface `T` — the only way `T` becomes resolvable by `MustInject`/`MustInjectAll`. `ref`'s own concrete registration must also be passed to `Providers(...)`. Panics immediately if `T` isn't an interface, or if `ref` is itself the result of another `ProviderAs` call (chaining). |

## Code Examples

### Basic Provider Usage

```go
package user

import "github.com/gonest/gonest"

type UserService struct{}

func NewUserService() *UserService {
	return &UserService{}
}

var UserServiceProvider_ = gonest.NewProvider(func(p *gonest.Provider) {
	p.Scope(gonest.ScopeSingleton)
	p.Constructor(NewUserService)
})
```

### Registering Interface Bindings with `ProviderAs`

In GoNest, reference variables end with a trailing underscore (`_`) by convention. To inject an interface rather than a concrete struct (analogous to NestJS `{ provide: 'IUserRepository', useClass: PgUserRepository }`), use `gonest.ProviderAs[T]`:

```go
package user

import "github.com/gonest/gonest"

type UserRepository interface {
	FindByID(id string) (*User, error)
}

type PgUserRepository struct{}

func NewPgUserRepository() *PgUserRepository {
	return &PgUserRepository{}
}

func (r *PgUserRepository) FindByID(id string) (*User, error) {
	return &User{ID: id}, nil
}

// 1. Define the concrete implementation provider (trailing _)
var PgUserRepository_ = gonest.NewProvider(func(p *gonest.Provider) {
	p.Constructor(NewPgUserRepository)
})

// 2. Map the concrete provider to the UserRepository interface (trailing _)
var UserRepository_ = gonest.ProviderAs[UserRepository](PgUserRepository_)

// 3. Register both in your Module (both concrete and interface refs are required)
var UserModule_ = gonest.NewModule(func(m *gonest.Module) {
	m.Providers(PgUserRepository_, UserRepository_)
})
```

### Resolving Dependencies with `MustInject` and `MustInjectAll`

Once the interface is registered with `ProviderAs`, resolve instances using the interface type:

```go
// Resolves the single registered implementation for UserRepository (panics if 0 or >1 matches)
userRepo := gonest.MustInject[UserRepository](owner)

// Resolves all registered implementations matching UserRepository interface
allRepos := gonest.MustInjectAll[UserRepository](owner)
```
